# Bahi Desktop Launcher (Placeholder)

This folder is reserved for the future Bahi desktop launcher shell (e.g., built with Electron or Tauri).

## Architecture Plan
- Serves as the native desktop shell for users and enterprise tenants.
- Integrates with Bahi's `@bahi/applications` registry to dynamically detect and launch installed or subscribed business applications (CRM, Sales, Inventory, Accounting, HR, Projects).
- Retains local offline cache, hardware integrations (e.g. barcode scanners, thermal receipt printers), and multi-window workspace capabilities.
